# Gate evidence

Milestone gate reports and their reproducible evidence belong in this directory. A gate report is added only by its corresponding gate task and cannot waive an incomplete dependency.

## Reports

- [Milestone 0 foundation gate](m0-foundation-gate.md) — PWS-0010; review in progress

Each report records the reviewed revision and environment, prerequisite status, automated and
manual evidence, known limitations, unresolved defects, owned future risks, and an explicit pass
or fail conclusion. A report distinguishes implemented controls from planned task ownership and
does not turn a policy baseline, synthetic construction assertion, sentinel test, or record-only
measurement into a release claim.
