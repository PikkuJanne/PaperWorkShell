# PWS-0807 packaged R2 qualification

## Disposition

**R2 failed the installed high-contrast keyboard-focus check.** When the
standard user tabbed from **Close case** to the selected **Pages** tab at
192 DPI (200%) with the Windows Aquatic contrast theme, the focused tab
received no visible indicator. UI Automation confirmed that Pages had
keyboard focus. A before/after comparison of the entire 1,582 × 1,032
application image found changes only at the button that lost focus. The
tab and its two-pixel surrounding margin were identical. This blocks
qualification of R2. Its successful exports and other observations below
remain evidence for this build.

Normal 96 DPI, normal 192 DPI and Aquatic 192 DPI each passed eight
keyboard focus and bounds observations, including two reverse steps.
The selected tab visibly changed in both normal-palette runs. The
display returned to the original 96 DPI, 1,024 × 768 desktop and
